# Stillwake

Codename. A 2D side-view space game: an always-moving ship salvages floating debris, Raft-style, and
turns it into Factorio-style automated production that grows and upgrades the ship; along the way it
lands on planets. Meditative pace. PC (Steam), online co-op for 4+ players in host-owned worlds.

Status: pre-production — planning. Game design so far: [docs/concept.md](docs/concept.md). Working
rules for people and agents: [CLAUDE.md](CLAUDE.md).
